# FlowProbe

**多协议网络与串口调试台**

[English](README.en.md) · 简体中文

[![下载最新版](https://img.shields.io/github/v/release/kevinLei736/FlowProbeClient?label=%E4%B8%8B%E8%BD%BD%E6%9C%80%E6%96%B0%E7%89%88&style=flat-square)](https://github.com/kevinLei736/FlowProbeClient/releases/latest)

</div>

把日常调试最常用的连接、收发、Mock、接口测试集中到一个桌面应用里，走统一的「连接 → 发送 → 接收 → 观察」工作流。
不必再为 TCP 开一个工具、串口开一个工具、Mock 再开一个 —— 也不必在几个窗口之间来回对时间戳。

名字取自工具本身在做的事：报文在链路上流动（flow），工具在链路中间下一根探针（probe），把流过的每一帧截下来看清楚。

> 本仓库只发布安装包。应用界面为简体中文。

## 功能详解

### TCP 与 UDP

四种角色，共用同一套发送区与时间轴。

| 角色 | 要填什么 | 能做什么 |
|------|---------|---------|
| TCP 客户端 | 目标地址 + 端口 | 连接、收发、断线指数退避重连、定时心跳 |
| TCP 服务端 | 监听端口（可指定网卡）| 多客户端接入，按连接单播或全体广播，可踢出指定连接 |
| UDP 客户端 | 目标地址 + 端口，可选固定本地端口 | 定向发送、`255` 广播、组播加入 |
| UDP 服务端 | 绑定端口 | 收包后按来源地址自动派生对端，可回全部或指定一个，空闲超时淘汰 |

**发送区可用设置**

| 设置 | 可选值 | 说明 |
|------|-------|------|
| 输入编码 | UTF-8 / HEX / Base64 | 选 HEX 可写 `AA 01 02`，空格与换行都忽略 |
| 追加结束符 | 不追加 / CR / LF / CRLF | 只对字节流协议开放 |
| 定时发送 | 毫秒周期 | 用于压测或维持链路 |

**收包与切帧**：TCP 是字节流，收到的一段不一定等于对方发的一条。可以按**结束符**、**固定长度**或**长度域**切帧，规则在会话高级设置里，改完立即生效、不必断开重连。UDP 天然按包边界，不需要切帧。

服务端监听失败（端口被占用）时**不会**退避重连 —— 那通常是配置问题，反复重试只会把真正的原因藏起来。

### WebSocket

| 客户端可用项 | 说明 |
|-------------|------|
| 地址 | 完整 URL，`ws://host:port/path` 或 `wss://…` |
| 子协议 | `Sec-WebSocket-Protocol`，多个用逗号分隔 |
| 自定义 Header | 一行一条 `Key: Value`，鉴权 Token 通常放这里 |
| Ping 间隔 | 大于 0 即开启心跳，用来穿过会掐断空闲连接的网关 |
| 自动重连 | 指数退避，每次尝试的失败原因写进连接生命周期日志 |
| 帧类型 | 输入编码选 UTF-8 发文本帧，选 HEX / Base64 发二进制帧 |

服务端可指定**监听端口 + 路径**（例如 `/ws`），路径不匹配的握手会被拒绝；客户端列表支持单播、广播与踢出连接。

### 串口

| 可用项 | 可选值 |
|-------|-------|
| 端口 | 自动枚举当前所有可用串口，插拔后点刷新重新枚举，不用重开应用 |
| 波特率 | 常用档位 + 手填非标准值 |
| 数据位 / 停止位 | 5/6/7/8 · 1/1.5/2 |
| 校验 | 无 / 奇 / 偶 / Mark / Space |
| 流控 | 无 / RTS-CTS / XON-XOFF |
| 线电平 | 显式控制 RTS / DTR，某些设备靠这两根线复位或进入下载模式 |
| 中断恢复 | 拔线按指数退避重连，插回去自己恢复 |

收到一片乱码时先把显示编码切到 HEX 再判断是不是波特率或校验位不对。

### MQTT 客户端

| 可用项 | 说明 |
|-------|------|
| 协议版本 | 3.1.1 与 5.0 |
| 传输 | `mqtt://` · `mqtts://` · `ws://` · `wss://` |
| 连接参数 | Broker 地址、Client ID、用户名密码、保持连接秒数、是否清除会话 |
| 订阅 | 通配符 `+` 匹配一层、`#` 匹配多层；每条订阅单独设 QoS，可临时停用而不删除 |
| 发布 | 主题、QoS 0/1/2、Retain 标志 |
| 遗嘱消息 | 连接非正常断开时由 Broker 代发，用来做在线状态检测 |

时间轴上每条消息都带主题名，可按主题过滤。

### Modbus 主站

三种链路：**Modbus TCP**、**Modbus RTU**（串口）、**RTU over TCP**（串口透传网关）。点表配置与链路无关，换传输方式不用重填。

| 点表列 | 可选值 / 说明 |
|-------|-------------|
| 名称 | 显示用，例如「1 号机温度」 |
| 数据区 | 保持寄存器 4x / 输入寄存器 3x / 线圈 0x / 离散输入 1x |
| 地址 | 0 基地址，与设备手册口径对齐 |
| 数据类型 | uint16 / int16 / uint32 / int32 / float32 / float64 / 位 |
| 字序 | 大端 / 小端 / 字交换 —— 跨字类型配错会读出天文数字 |
| 系数与偏移 | 工程值 = 原始值 × 系数 + 偏移，单位一起显示 |
| 轮询开关 | 可单独关闭某个点位，不必删掉 |
| 写入 | 支持就地写值 |

链路可靠性方面：请求**串行排队**并保持最小间隔，避免把从站打爆；响应超时可配、失败按次数重试；事务号不匹配的响应直接丢弃并记日志；**地址相邻的点位自动合并成批量读**，合并间隔可配；异常响应解析出异常码并给中文说明，时间轴上以红色 `E<码>` 徽标标记。

### Modbus 从站模拟

主站面板只能证明「我发出去的请求长这样」，证明不了「点表配得对不对」—— 字序、地址偏移、系数这三样配错之后依然读得出数字，只是数字是错的。所以需要一个自己完全掌握真值的从站来对账。

| 数据区配置项 | 可选值 / 说明 |
|-------------|-------------|
| 数据区 / 起始 / 数量 | 声明这台设备「有哪些地址」，0 基地址 |
| 初值 | 启动时填充，位区自动夹到 0/1 |
| 只读 | 勾上后保持寄存器与线圈也拒绝写入，用来验证主站的错误处理分支 |
| 自动变化 | 递增斜坡 / 正弦波 / 随机 / 位翻转，可配周期、上下限与步进 |
| 从站地址 | Unit ID，不匹配时静默丢弃而不回异常码；也可勾「接受任意从站地址」让一个会话冒充整条总线 |

| 故障注入 | 用来验证什么 |
|---------|-------------|
| 应答延迟 | 主站的超时与重试分支是否真的生效 |
| 丢包率 | 随机无应答下主站会不会卡死或误判离线 |
| 强制异常码 | 固定返回 0x01 / 0x02 / 0x03 / 0x04 / 0x06，检查主站的异常提示与恢复 |

只有声明过的地址才存在：主站读一个没声明的地址会收到异常码 `0x02 非法数据地址`，而不是悄悄返回 0 —— 如果越界也给 0，「地址填错一位」这个经典问题会被完美掩盖。

实时值可就地修改（位区点一下翻转，寄存器点开改值），主站写进来的值会实时反映；改数据区即时生效、不断开已连接的主站，改链路参数才需重启监听；发送框也能手动置值，格式 `holding 5 1234`。
### HTTP Mock 服务

在本机启动一个**真实的** HTTP(S) 服务，按规则返回可配置响应。启动后浏览器、Postman、真实 App 都能直接访问。

| 路由匹配维度 | 可选值 |
|-------------|-------|
| 方法 | GET / POST / PUT / DELETE / PATCH / OPTIONS / HEAD / ANY |
| 路径 | 精确 `/api/health` · 占位 `/api/users/:id` · 通配 `/files/*` · 正则 `re:^/v[0-9]+/ping$` |
| Query | 例如 `status=ok` |
| Header | 例如 `x-token: abc` |
| 优先级 | 多条规则排序，取第一条命中的 |

| 响应模式 | 能做什么 |
|---------|---------|
| 静态 | 固定状态码、Header 与响应体 |
| 模板 | 响应体里插占位符回显请求数据或生成动态值 |
| 脚本 | 沙箱里跑一段 JS，做条件分支、鉴权校验与有状态计数，返回 `{ status, headers, body }` |

模板可用占位符：

```
{{path.id}}       路径参数
{{query.page}}    查询参数
{{body.userId}}   请求体 JSON 字段（支持 a.b.c）
{{header.token}}  请求头
{{now}} {{ts}} {{uuid}} {{sequence}} {{randomInt}}
```

**场景库**：同一组路由存多套响应（正常 / 慢响应 / 500 / 鉴权失败），顶部下拉一键切换，不用逐条改回来 —— 前端要复现「超时怎么办」时这一步最省事。

**代理透传与录制转路由**（四步把真实接口固化成 Mock）：

1. 打开代理透传，填真实后端地址，未命中的请求转发过去
2. 让 App 正常跑一遍，请求日志记下真实的请求与响应
3. 打开「录制转路由」，勾选要固化的条目批量生成路由，路径里的数字 id 自动变成 `:id` 参数
4. 关掉代理，从此这些接口由本地返回，后端挂了也能继续开发

**HTTPS**：勾上即自动生成自签证书，也可换成自己的证书对；证书面板能看有效期、SAN 与私钥是否匹配。移动端信任自签证书需另外装根证书，这是系统层面的限制。

其他可用项：每条路由可设固定延迟复现慢接口；请求日志按路径 / 方法 / 状态码过滤并导出 HAR；默认只监听 `127.0.0.1`，要让手机访问需改成监听全部网卡（此时局域网内任何人都能访问）。

### HTTP 接口测试

| 请求可用项 | 可选值 |
|-----------|-------|
| 方法与 URL | 全部常用方法 |
| Query / Header | 键值表，可逐行启停 |
| 请求体 | JSON / 表单 / 原始文本 / 无 |
| 认证 | Bearer Token · Basic · API Key（放 Header 或 Query）|
| 变量 | 把 `baseUrl`、`token` 抽成变量用 `{{baseUrl}}` 引用，切环境即切一整套配置 |
| 响应查看 | Body（可格式化 JSON）· Header · 耗时 · 体积 |
| 历史 | 每次请求与响应摘要留档，一键回填重发 |

| 断言类型 | 说明 |
|---------|------|
| 状态码 | 等于 / 属于某一组 |
| 响应时间 | 小于阈值 |
| JSON 字段值 | 按路径取值比对 |
| 包含文本 | 响应体包含某段字符串 |

**集合与批量运行**：一组接口按顺序存成集合一键执行；前一个响应里的字段可提取成变量供后面使用（登录拿 token 再调业务接口这种链路）；跑完出报告，含每步断言结果、耗时与失败原因，可导出。

**定时巡检**：集合可设周期自动跑，断言失败发系统通知。调度挂在应用外壳上，**关掉面板仍在后台运行**。

### 报文分析

| 能力 | 可用项 |
|------|-------|
| 协议解析模板 | 按顺序声明字段名、类型、长度、字序 → 报文展开成字段表；支持系数换算、枚举映射（`0=停机 1=运行`）与校验位核对；模板按模块归属，地址类模板只出现在 Modbus |
| 数值曲线 | 把解析出的数值字段随时间画成折线，带极值统计，可导 CSV |
| 报文对比 | 勾选两条报文做字节级 diff：HEX 视图标出不同字节位置，字段表视图直接告诉你哪个字段变了 |
| 标注与书签 | 时间轴任意一行加 ☆ 并补一句「为什么可疑」；存的是自洽快照（时间、方向、字节、HEX 片段、说明），清屏、重启甚至删掉原会话之后依然读得懂；原会话还在时可「跳回去」看上下文；可按会话筛选并导出 Markdown |
| 录制与回放 | 把一段收发存成文件，按原时序重放，倍速 0.25×–10×，把「偶发一次的现场」变成可反复重现的用例 |

### 告警与监控

| 可用项 | 说明 |
|-------|------|
| 规则对象 | 模板解析出的字段：温度 > 80、状态字 ≠ 0、校验不符… |
| 命中动作 | 高亮该报文行 + 系统通知 |
| 自动断开 | 可设「命中后断开会话」，把现场原样保留，不让后续报文冲掉缓冲 |
| 冷却 | 同一条规则有冷却时间，避免每秒几十帧时通知刷屏 |
| 告警中心 | 报文告警与巡检失败汇成一条时间线，含来源会话、触发说明与当时的报文快照，可导出 CSV |

规则在应用启动时就加载，不需要先打开告警中心面板 —— 否则重启后第一批报文会因为规则表还是空的而被静默跳过。

### 历史、搜索与看板

| 可用项 | 说明 |
|-------|------|
| 报文历史 | 报文与 HTTP 请求落本地数据库，关掉应用也在；分页翻阅、按会话与时间筛选、导出 CSV |
| 全局搜索 | 一个关键字横扫所有历史报文与请求，文本与 HEX 互相命中（搜 `4142` 也能找到 `AB`）|
| 看前后文 | 命中行可直接展开那条报文附近的若干条，不用先跳回会话 |
| 数据看板 | 全局吞吐、包长分布、会话状态、Mock 错误率与响应分位一屏看完 |
| 容量管理 | 历史库有上限与保留策略，可在设置里调整或手动清理某个会话的记录 |

| 可用项 | 说明 |
|-------|------|

| 导入导出 | 「文件 → 导出配置」把整个工作区存成一个文件，换机器或分享给同事时导入即可 |

### 自动更新

入口在**帮助 → 检查更新**。不需要填任何服务器地址，更新地址在打包时已固定在安装包里，装好即用；下载是匿名的，不需要账号或令牌。

| 开关 | 默认 | 说明 |
|------|------|------|
| 启动后自动检查一次 | 开 | 启动约 8 秒后在后台查一次，避免和恢复会话、开监听端口抢资源 |
| 发现新版本后自动下载 | 关 | 装新版要重启，而重启会断开正在跑的连接，所以默认让你自己决定时机 |

有新版本时「帮助」菜单项会直接写成「有新版本…」，下载完变成「有新版本可安装…」，不用主动进面板看。检查失败会分类给出中文原因：发布方还没发正式版本、清单文件缺失，还是这台机器连不上更新服务器。

## 数据存在哪

所有数据只存在本机，不上传任何服务器。

| 平台 | 位置 |
|------|------|
| Windows | `%APPDATA%\flowprobe\` |
| macOS | `~/Library/Application Support/flowprobe/` |

目录里是工作区配置 `workspace.json`、报文历史库 `history.db` 与自签证书。
应用内「文件 → 打开工作区所在目录」可直接跳过去，方便备份或迁移。

从 1.18.0 及更早版本升级过来时，数据目录会从 `debug-toolbox` 自动复制到 `flowprobe`：是复制不是移动，旧目录保持原样，需要时还能装回旧版本继续用。

## 常见问题

| 现象 | 先查这里 |
|------|----------|
| TCP / WebSocket 连不上 | 地址端口是否写错、对端是否在监听、本机防火墙是否拦了。连接生命周期日志里有每次尝试的失败原因 |
| 服务端启动失败 | 端口被别的程序占用，或用了 1024 以下的特权端口。换一个高位端口 |
| 收到一片乱码 | 把显示编码切到 HEX。串口场景先怀疑波特率与校验位，网络场景怀疑对方是二进制协议 |
| 串口列表里没有设备 | 点端口下拉旁的刷新重新枚举；确认驱动已装、线已插好、没被其他串口工具占用 |
| 手机访问不到本地 Mock | Mock 默认只监听 `127.0.0.1`，改成监听全部网卡，并确认手机与电脑同网段、防火墙放行 |
| Modbus 读数是天文数字 | 几乎总是字序或数据类型配错。用从站模拟填一个已知值来对账 |
| 检查更新提示「发布方尚未启用更新服务」| 装的是 1.20.0 及更早的版本，那些包里还没有更新地址。手动装一次新版即可，之后就能一路自动更新 |

更多内容在应用内按 `F1` 打开使用文档。
